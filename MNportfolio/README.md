# Marie Anjilee V. Naces - Student Portfolio

Plain HTML, CSS and JavaScript. No build step.

Files: index.html, style.css, script.js, images/

Preview: open index.html in a browser (or use VS Code Live Preview).

Publish with GitHub Pages: create a public repository named `portfolio`, upload the CONTENTS of this folder
(index.html beside the images folder), then Settings > Pages > Deploy from a branch > main > /(root).
Your site will be at https://YOUR-USERNAME.github.io/portfolio/

To add an email button, edit the Contact section in index.html (see the comment there).
